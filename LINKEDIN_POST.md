# LinkedIn Post - Heart Failure Prediction ML Project

## Post Content

Excited to share a machine learning project I've built: Heart Failure Prediction using Clinical Data

I developed an end-to-end classification pipeline that predicts heart failure risk with 86.96% accuracy and 0.9298 ROC-AUC score.

**Project Highlights:**

Model Performance:
- Test Accuracy: 86.96%
- ROC-AUC: 0.9298
- Cross-Validation: 85.83% (+/- 3.19%)
- Sensitivity: 89.14% (catches most at-risk patients)

Technical Implementation:
- 4 classification algorithms: Logistic Regression, Random Forest, Gradient Boosting, SVM
- 5-fold stratified cross-validation for robust evaluation
- Balanced class weights to handle data imbalance (55/45 split)
- SHAP explainability for interpreting model decisions
- Comprehensive unit tests (15+) with pytest

Key Features:
- ST segment characteristics (33%+ feature importance)
- Maximum heart rate during exercise
- Exercise-induced angina indicators
- Metabolic factors (cholesterol, blood pressure)

Production-Ready Implementation:
- Structured logging throughout pipeline
- Error handling and input validation
- Model persistence with joblib
- JSON metrics tracking
- Automatic visualization generation (ROC curves, confusion matrices)
- Comprehensive documentation

Tech Stack:
Python, scikit-learn, XGBoost, SHAP, pandas, numpy, matplotlib, seaborn, pytest

This project demonstrates full ML pipeline development from data preprocessing through model evaluation and deployment-ready code. All code is open source on GitHub with detailed documentation.

Open to feedback and collaboration. Let me know if you're working on similar healthcare ML projects!

GitHub: https://github.com/patrusgrg/heartfailure-prediction
